# reaction_unity

Un jeu de réaction rapide où il faut cliquer quand un cercle apparait à l'écran.

- La méthode `Trigger()` du script `GameManger.cs` démarre le jeu et permette de jouer (avec un bouton d'arcade par exemple)
- La la méthode `GetUIElementVisible()` retourne un `bool` pour savoir si un élément est visible à l'écran (pour synchroniser avec la dEL d'un bouton d'arcade par exemple).
